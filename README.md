# 命理 · 坦诚读盘 (mingli-reading)

一套给 AI 用的算命 skill——**坦诚的那种，不说哄人的好听话。**

大多数"AI 算命"的毛病是：玄、飘、专挑好听的说。你问它命好不好，它总有办法把每个人都夸成"上等命、大器晚成、贵人相助"。这套东西反着来——它把算命当成一件**能被你回头验证**的事，所以它必须诚实。

## 四条纪律

这个 skill 的价值不在"算得更准"，在它给读盘立的四条规矩：

1. **只交付形状，不假装刻度。** 命算得出结构和倾向（身弱、财旺、婚迟、该走什么路），算不出具体哪年出什么事。它会把"形状"笃定地讲给你，一旦落到"刻度"（哪一年、哪件事）就明确标成猜测——而且**算错了会认**。好先生的权威，来自清楚自己算得出什么、算不出什么。

2. **诚实压过安慰。** 不描金、不搞"各有福债"的平均主义。命盘就是有好坏高低，该排档就排档，把你诚实放在你那一档。你要真话，它给真话。

3. **象 vs 字。** 十神那张表是坐标，不是体验。它会先认领你真实的体感，再回溯到盘里真正制造它的机关——而不是被字面骗了。

4. **落回活法，交还主权。** 每一卦最后都翻译成你能做的事，然后把决定权还给你。命给形状，成败在你手里——**天行健，自强不息**那半，是你的，不是卦里的。

## 特色手法："改一个字"

它能做一件别的算命少做的事：八字改不了，但把"改一个字后的整盘"当一个真人读透、跟你原盘并排，抽出那个**整体形态**（性格怎么变、生活怎么变）供你模仿。配着天干看地支、用大运验证、诚实标出哪些能修（性情活法）、哪些补不满（先天结构）。

## 安装

把 `mingli-reading/` 整个目录放进你的 skills 目录：

```bash
# Claude Code / 支持 skills 的客户端
git clone https://github.com/CCRobert1997/mingli-reading.git \
  ~/.claude/skills/mingli-reading
```

之后报个生辰（年月日时 + 性别 + 出生地），它就会自动挂上这套方法。

## 一句诚实的话

这是**命理演绎**，不是预知未来。它不会（也不该）对你现实里高风险、不可逆的决定下"命定"式的断言——它只给形状、把拍板权还给你。当个镜子照照自己、理理思路，挺好；拿它替你做决定，别。
