# 排盘硬算法

排盘是纯计算，别凭感觉。拿不准就用 Bash/python 实算，算完拿已知锚点验证。

## 天干地支

- 十天干：甲乙丙丁戊己庚辛壬癸（阳/阴/阳/阴/阳/阴/阳/阴/阳/阴）
- 十二地支：子丑寅卯辰巳午未申酉戌亥
- 六十甲子循环：甲子=1 … 癸亥=60

## 年柱

- **以立春分界**（约每年 2/3–2/5）。立春前出生 → 算上一农历年的干支。
- 年干支序号：`((公历年 - 4) mod 60)` → 甲子=0 起算（即 1984=甲子）。等价：`(年-3) mod 10` 定天干（1=甲），`(年-3) mod 12` 定地支（1=子）。
- 关键陷阱：1 月、2 月初出生的人，年柱极易排错一位——务必先判是否过了当年立春。

## 月柱

- **以节气"节"分界**，不是农历月初一。十二节：立春(寅)、惊蛰(卯)、清明(辰)、立夏(巳)、芒种(午)、小暑(未)、立秋(申)、白露(酉)、寒露(戌)、立冬(亥)、大雪(子)、小寒(丑)。
- 生日在两个节气之间，取前一个"节"所属的月支。
- **五虎遁**（年干 → 正月/寅月天干）：
  - 甲己之年 → 丙寅起
  - 乙庚之年 → 戊寅起
  - 丙辛之年 → 庚寅起
  - 丁壬之年 → 壬寅起
  - 戊癸之年 → 甲寅起
  - 从寅月顺排到生月。

## 日柱（最容易算错，务必验证）

- 干支序号 = `(JDN + 50) mod 60`，其中 1=甲子 … 60=癸亥（若 mod 得 0 则为 60=癸亥）。
- JDN = 儒略日数。锚点：**1900-01-01 = JDN 2415021 = 甲戌**。
- **验证例**：2000-01-01 → JDN 2451545 → `(2451545+50) mod 60 = 55` → 戊午。✓
- 实操：写几行 python 由公历算 JDN，再套公式，再核一个你手边确定的盘。别手推 mod。

## 时柱

- 时辰：子(23–01)丑(01–03)寅(03–05)卯(05–07)辰(07–09)巳(09–11)午(11–13)未(13–15)申(15–17)酉(17–19)戌(19–21)亥(21–23)。
- **真太阳时**：有出生地经度就修正（每偏离标准经线 1° ≈ 4 分钟），跨时辰边界时尤其要修。
- 子时跨日：晚子时（23–24）算次日日干配子时；早子时（00–01）算当日。断法有派别差异，注明即可。
- **五鼠遁**（日干 → 子时天干）：
  - 甲己日 → 甲子起
  - 乙庚日 → 丙子起
  - 丙辛日 → 戊子起
  - 丁壬日 → 庚子起
  - 戊癸日 → 壬子起
  - 从子时顺排到生时。

## 藏干（地支本气/中气/余气）

- 子=癸／丑=己癸辛／寅=甲丙戊／卯=乙／辰=戊乙癸／巳=丙戊庚／午=丁己／未=己丁乙／申=庚壬戊／酉=辛／戌=戊辛丁／亥=壬甲
- 数十神、看通根透干、判身强弱，都要把藏干算进去。月令藏干权重最重。

## 大运

- **阳年男 / 阴年女：顺排**；阴年男 / 阳年女：逆排。从月柱起。
- 起运岁数：从生日数到（顺排）下一个节 /（逆排）上一个节的天数 ÷ 3（3 天 = 1 岁）。
- 每步大运管 10 年。
